# Сайт Route 66 Coffee Diner

**Онлайн-витрина:** https://whhhsww.github.io/route66-coffee-diner/

> На GitHub Pages работает витрина: 3D-видео, меню с ценами и поиском, QR-код и контакты. Отзывы и редактирование владельцем там скрыты, потому что GitHub Pages не запускает сервер и сохранять данные негде. Полная версия работает через `node server.js` или на PHP-хостинге (см. ниже). Меню на витрине берётся из `data/menu.json`. Чтобы обновить витрину после изменений, выполните `node build-pages.js --publish`: сайт обновится за 1–2 минуты.

Весь текст на сайте — на украинском языке. Что есть на сайте:

- главный экран с 3D-анимацией (`public/assets/hero.mp4`) в тёмно-оранжевых и белых тонах;
- **меню** с ценами, поиском и быстрыми кнопками категорий (12 категорий, всё перенесено с фото меню);
- **отзывы**: гости ставят звёзды и пишут текст, средняя оценка считается автоматически;
- **QR-код**: можно выбрать, куда он ведёт (меню / отзывы / главная), скачать PNG, распечатать табличку на стол или поделиться ссылкой;
- раздел «О нас» и контакты;
- **админ-панель** по адресу `/admin`: меню, цены, отзывы, контакты, домен, пароль.

## Запуск на компьютере

Нужен Node.js (уже установлен). Дважды кликните `start.bat` или выполните:

```
node server.js
```

Затем откройте http://localhost:8066 (админка: http://localhost:8066/admin).

## Редактирование прямо на сайте (для владельца)

1. Внизу сайта нажмите **«🔒 Вхід для власника»** (или откройте адрес сайта с `#admin` в конце) и введите пароль.
2. Сайт переходит в **режим редактирования**: нажмите на любое название, описание, объём или цену и впишите новое значение.
3. У каждой позиции есть кнопки: ↑↓ меняют порядок, 👁 скрывает позицию, которой нет в наличии, 🗑 удаляет, «+ обʼєм / ціна» добавляет размер, а в выпадающем списке выбирается метка «новинка / хіт / сезон».
4. У категорий можно поменять иконку, название и подзаголовок. Внизу каждой категории есть «+ Додати позицію», вверху меню — «+ Нова категорія» и массовое изменение цен в %.
5. В нижней панели нажмите **«Зберегти зміни»**, и гости сразу увидят обновлённое меню.
6. **«⚙ Контакти і тексти»**: адрес, телефон, часы, соцсети, слоган, «О нас», объявление вверху и домен для QR.
7. В разделе отзывов у каждого отзыва есть кнопки «Сховати» и «Видалити».
8. **«🔑 Пароль»** меняет пароль, **«Вийти»** выходит из режима.

## Админ-панель (расширенная, по адресу /admin)

- Стандартный пароль: **`route66admin`**. Сразу смените его.
- **Меню і ціни**: менять названия, цены, объёмы (у позиции может быть несколько цен, например 250/350/500 мл), добавлять и удалять позиции и категории, менять порядок кнопками ↑↓, скрывать кнопкой 👁 то, чего нет в наличии, ставить метки «новинка / хіт / сезон», добавлять ссылку на фото. Есть массовое изменение цен в % и резервная копия меню в файл.
- После правок нажмите **«Зберегти меню»**, и изменения сразу появятся на сайте.
- **Відгуки**: скрыть, опубликовать или удалить отзыв. В настройках можно включить премодерацию: тогда новые отзывы видны только после одобрения.
- **Налаштування**: адрес, телефон, часы работы, Instagram/Telegram/Facebook, текст «О нас», объявление вверху сайта и **домен**.

## Когда появится домен

1. Откройте `/admin` → «Налаштування» → поле «Адреса сайту (домен)» и впишите домен, например `route66coffee.com.ua`.
2. Сохраните настройки. Все QR-коды начнут вести на новый домен. Перепечатайте таблички.

## Как выложить в интернет

**Вариант А — обычный хостинг с PHP** (самый дешёвый, подходит почти любой украинский хостинг):

1. Содержимое папки `public/` загрузите в корень сайта (`public_html` / `www`).
2. Папку `data/` положите **на уровень выше** корня сайта (рядом с `public_html`). Если хостинг этого не позволяет, положите `data/` внутрь `public_html`: файл `.htaccess` закроет к ней доступ.
3. У PHP должно быть право записи в папку `data/` (обычно права 755 или 775).
4. Нужен Apache с `mod_rewrite` (на хостингах он почти всегда включён). Всю работу делает `api.php`, `server.js` на таком хостинге не нужен.

**Вариант Б — хостинг с Node.js** (VPS, Render, Railway и т. п.): загрузите всю папку `site/` и запустите `node server.js`. Порт задаётся переменной `PORT`.

> Перед публикацией обязательно смените пароль администратора.

## Структура

```
site/
  server.js        сервер на Node.js (сайт + API)
  start.bat        быстрый запуск на Windows
  data/            меню, отзывы, настройки (это и есть «база данных»)
    menu.json
    reviews.json
    settings.json
    auth.json      пароль (создаётся автоматически, хранится в виде хэша)
  public/          сам сайт
    index.html     главная страница
    admin.html     админка
    api.php        API для PHP-хостинга
    .htaccess      настройки для PHP-хостинга
    css/ js/ assets/
```

## Что стоит проверить по меню

Часть названий на фото кассы была обрезана, их я восстановил по смыслу. Проверьте и при необходимости поправьте в админке: «Колумбія», «Барні», «Мурашник», «Десерт-кейкпопс», «Банан у кокосі», «Горішки з начинкою», «Фігурна цукерка», «Брелок «Щит»», «Кекс на заквасці». У позиций «Раф кава», «Матча лате» и «Зимовий джміль» в кассе не было цены: на сайте показано «ціну уточнюйте», впишите цены в админке.
